# Small Steps English

一个面向个人的英语学习 Web 项目：发现内容 → 分级阅读 → 收藏表达 → 间隔复习。

## 启动

需要 Node.js 24 或更新版本。

```bash
npm install
npm start
```

打开 http://127.0.0.1:3000 。开发时使用 `npm run dev` 自动重启后端。

无需模型密钥即可阅读 3 篇内置原创练习、同步 RSS、收藏表达和复习。数据保存在 `data/english.sqlite`，重新启动不会丢失；首次启动自动建表。

## 功能

- **今日学习**：一键开始轻量词汇练习，接同批词的语境拼图与熟词短文；保留推荐阅读与进度。
- **自由探索**：按“用起来、读与听、词与记忆”组织已有学习工具。
- **我的积累**：分别展示记忆、表达、听辨的具体词句和篇目，区分独立完成、提示辅助与自评。
- **发现内容**：启动时及每小时同步 BBC World / Technology RSS，支持手动刷新、主题筛选、关键词搜索和原文跳转。也可只选择一篇文章，粘贴英文全文同步到本地，自动统计篇幅、阅读时间、估算难度、关键词与重点句；精读时可选中原文添加标注，并记录“已练习”状态。当前读取每个源最新 20 条，页面最多显示 60 条。
- **生成练习**：选择 A2/B1/B2/C1 难度、生活/职场/旅行/科技主题，可输入场景或从新闻摘要生成。输出英文短文、逐段翻译、表达与例句、阅读理解题。
- **阅读**：切换翻译、浏览器语音朗读、答题反馈、完成记录与表达收藏。
- **复习短文**：将真正学过的单词和短语放进同一篇主题文章，支持高亮精读、关键词挖空、看中文背英文、全文朗读和独立完成记录。
- **间隔复习**：只复习已经学过且到期的词。收藏与导入只加入新词列表，首次学习评分后才安排复习，重复收藏不重置进度。
- **我的书架**：保存内置及生成内容，展示收藏表达和复习日期。
- **生词本**：手动添加、编辑单词与短语，补充双语例句和记忆笔记；分类、搜索、排序、重点标记、遮住释义和归档恢复。原有文章收藏自动出现在生词本中。
- **双向练习**：中译英、英译中、双向混合；输入答案或翻卡自测；按分类、单词/短语、重点词、薄弱项筛选，随机抽取每组 5–100 个词条。
- **词书**：五本可预览的精选词书，包含雅思专项，支持勾选、分批或整本导入；选择单本词书、个人收藏或全部词条练习。

## 选择词书与导入

打开 http://127.0.0.1:3000/#books 。目前内容：

| 词书              | 数量                   | 来源                                |
| ----------------- | ---------------------- | ----------------------------------- |
| NGSL 日常核心精选 | 40 个单词              | NGSL 1.2 官方开放词表选编           |
| BSL 商务表达精选  | 40 个单词              | BSL 1.2 官方开放词表选编            |
| NAWL 学术阅读精选 | 40 个单词              | NAWL 1.2 官方开放词表选编           |
| 日常实用短语      | 30 个短语              | Small Steps 原创整理                |
| 雅思备考主题精选  | 6,512 条去重词头及短语 | NGSL / NAWL / ECDICT + 原创主题精练 |

前三本均为**精选改编，并非完整官方词书或官方中文译本**。原词表采用 CC BY-SA 4.0 授权，中文释义由本项目编写；内容包同样以 CC BY-SA 4.0 提供。各词书预览页包含作者、来源和授权链接，详细说明见 [WORDLIST-LICENSE.md](WORDLIST-LICENSE.md)。三个选编词书的全部英文词头均已与对应官方 CSV 核对。

1. 点击封面预览词条和中文释义。大词书默认每页 50 条，可切换为 100 / 200 条，按英文/中文、学习层和状态筛选，点击“筛选词条”应用。词表顶部和底部可输入页码，点击“跳转”或按回车到指定页；全选只选择当前页，翻页或筛选后清空勾选。下一批 10 个和批量导入均针对当前筛选结果，清空筛选即可导入整本。
2. 导入后点击“练这本”，练习设置会自动选中该词书。中译英、英译中、翻卡、薄弱项与到期范围均可继续使用。
3. 在生词本的“词条来源”或练习页的“练习内容”中，切换全部词条、某本词书或个人收藏。
4. 词书新建的卡片默认只属于词书。打开词条编辑，点击“加入个人生词本”，即可让它同时进入个人收藏；移出个人收藏只改变标记，不删除词条。
5. 基础词已掌握时，在预览中点击“快速标熟悉”，扫读英文与释义，勾选或全选本页，再点击“标为熟悉”。“全选本页”“清空勾选”和页码跳转位于固定操作栏，滚动到词表中段仍可直接操作。未导入词会自动加入词库并停止学习、复习与提醒，不计入累计学过。相同英文与释义共用卡片，已导入的其他词书同步更新进度；不同释义不合并，已归档词跳过。
6. 误标后筛选“已熟悉”，勾选并点击“恢复学习”。未学词回到新词列表，学过的词立即进入待复习，历史记录保留；恢复操作不会导入未导入词。

重复导入同一词条会跳过。跨词书或已有个人词条中，英文与释义相同时复用卡片，保留多个词书来源以及笔记、分类、归档状态、个人收藏标记和复习时间；同词不同义分别保留。词书之间有重叠，因此总目录词条数可能大于实际独立卡片数。复用的卡片共享学习进度；已归档词条需手动恢复后才能参与练习。

首页和生词本显示可点击的学习积累：**累计学过**指完成过首次评分（含后来标记熟悉的词），**正在学习**指学过且未标熟悉，**已熟悉**仅指手动确认无需复习，**尚未学习**指未评分且未标熟悉。点击统计会清除旧搜索、分类和类型条件，展示对应词条；生词本统计跟随所选来源。统计包含单词与短语，以未归档学习卡片计数，同词不同义分别计数，跨书复用不重复累计。

词书封面和预览显示**学习百分比 =（正在学习 + 已熟悉）/ 全书词条数**，仅导入不增加学习百分比，不代表长期掌握率。已归档词条保留在全书分母中，但不计入已学习或熟悉；恢复归档后按保留的记录重新计入。每本书以本书条目为单位，共用卡片在所属词书同步进度。点击百分比或统计数字可查看、搜索、分页浏览对应条目；“尚未学习”包含尚未导入的词条。导入数量单独展示。非常小的非零百分比显示为 `<0.1%`，未全部完成时不会四舍五入到 100%。

词书内容随项目提供，导入和练习无需外网或 AI。尚未导入的词条不会进入复习队列。可在 `server/wordbook-catalog.js` 中扩充词书，但需保持书籍和词条 ID 稳定，并提供真实来源及相应授权说明。

### 雅思专项

“雅思备考主题精选”共 **6,512 条**，包含原来的 120 条主题精练和新增的 6,392 条词典词条。全库按英文词头及短语去重，ECDICT 明确标注的屈折变形归并到原形。

| 学习层     |  条数 | 用途                       |
| ---------- | ----: | -------------------------- |
| 高频基础 1 |   998 | 优先补齐常用词             |
| 高频基础 2 |   992 | 日常阅读与听力             |
| 高频进阶   |   800 | 扩大一般语境覆盖           |
| 学术阅读   |   942 | 学术语境与论述             |
| 备考拓展   | 2,660 | ECDICT 社区 IELTS 标签补充 |
| 主题精练   |   120 | 原创例句、话题与搭配       |

各层数量为跨来源去重后保留数量，不是原始词表规模。NGSL 输入 2,809 行，NAWL 教学下载文件实读 959 个词头（官网概述为 957，记录在清单中）。ECDICT 的 IELTS 标签来自社区，并非官方考试范围。

全部词条有中文释义。扩展部分采用 ECDICT 词典释义并自动清洗、少量人工补订，**尚未逐条人工审校，不保证附有例句**。原有 120 条仍保留原创双语例句：10 个主题各 12 条，涵盖教育与学习、环境与能源、科技与创新、健康与生活方式、工作与经济、城市与交通、社会与公共政策、文化与媒体、图表与数据描述、论证与观点表达。

导入新词时会自动创建相应的“雅思·主题”分类，并保存主题笔记。练习时同时选择本书和分类即可专练一个话题；核对答案后可看到双语例句，也可在编辑词条时查看和修改。若词条与已有个人卡片完全相同，则按现有去重规则保留旧卡片的例句、分类和笔记，不覆盖用户内容。

IELTS 官方评分没有“6.5 分必须背多少单词”的固定门槛。5,000–6,000 的认读词汇量可作为实用备考规划的参考范围，不能换算成分数，词条数也不等于词族数。还需练习语境中的理解、准确用词、搭配与同义改写。评分依据见 [IELTS 官方写作评分资料](https://ielts.org/take-a-test/preparation-resources/writing-test-resources)。建议先高频基础，再学术阅读，同时练主题搭配；已掌握词可标记熟悉。

内容入口为 `server/ielts-wordbook.js`，扩展数据及来源校验清单为 `server/data/ielts-expanded.json`。运行应用无需下载原始词典；重新构建使用 Python 3.8+ 和 Node.js 24：

```bash
npm run build:lexicon
```

脚本从固定 URL 获取 NGSL、NAWL、ECDICT，校验 SHA-256（ECDICT 固定 commit），缓存到 `.artifacts/lexicon-sources`。来源发生变化时失败退出，不静默替换。授权及处理方式见 [WORDLIST-LICENSE.md](WORDLIST-LICENSE.md)。词库扩充不自动导入、不重写已有卡片，熟悉标记、学习进度和个人编辑继续保留。生词本每页显示 50 条，搜索覆盖全部匹配卡片。

## 统一词库与例句回顾

打开 http://127.0.0.1:3000/#words 浏览统一词库，或 http://127.0.0.1:3000/#sentences 回顾例句。

- **一个词，一份词条身份**：按规范化英文词头生成稳定编号，和词书无关。同一个词在雅思、商务、学术等词书中指向同一详情，汇总来源、词性和不同释义。词书是选词集合，新增词书不会创建另一套词条身份。
- **词条与学习卡片分层**：同英文、同释义跨词书继续复用卡片与 FSRS 进度；同词不同义或不同释义版本归属同一词条但保留独立卡片。本次不凭拼写相同强行合并既有释义和学习历史。
- **例句与词条多对多关联**：一个词可以有多条例句，一句也能关联多个词。例句按完整英文与中文译文去重，所有来源保留。生词本编辑页与练习答案中可跳转统一词条，再看关联例句；例句中的关联词也可点击回到词条。
- **例句回顾**：可筛选全部、收藏、尚未回顾或关联到期词的例句，先看中文尝试表达，再揭晓英文和关联词。按“本次能表达 / 还需巩固”记录结果，后者会收藏本句；同一次评分重试不重复计数。优先回顾尚未看过及最久未回顾的句子，回顾记录持久保存。
- **个人例句**：在词条详情中添加双语例句，可填写其他已有单词或短语，建立共同关联。新增、收藏及回顾句子不会把关联词全部标为已学或熟悉，也不会重置单词复习时间。

首批内容来自原有 120 条原创雅思主题例句和 9 条内置阅读例句，均保留来源；用户补充的双语例句、后续生成的阅读例句也会纳入。精选例句不等于名人名言，当前没有把未经核查的名句放入词库。

`vocabulary_words` 保存统一词条，`vocabulary_sources` 关联词书/卡片/阅读中的释义，`sentences` 保存句子与收藏状态，`sentence_words` 建立关联，`sentence_recalls` 单独记录回顾。启动时及词条变动后重建来源索引，句子收藏与历史保留。已有 cards、book_entries、reviews 和 FSRS 字段保持原语义。

## 词语联想与辨析

在统一词库首页点击 `conservation ↔ preservation` 示例，或打开任意词条的“联想与辨析”。首批提供 8 组本地整理的关系，区分**近义辨析、形近易混、同词族**，展示共同点、使用区别、常见搭配及原创双语例句，并提供 Cambridge 释义参考链接。例句可以朗读，关联词可双向跳转。没有整理内容的词显示空态，不凭拼写相似推断近义关系。

例如 conservation / preservation 都涉及保护与保存，但前者常用于自然保护和资源节约，后者更强调保存、维持状态；自然与历史建筑保护语境中仍有重叠。辨析不表示任何场景都可互换，也不把资源使用与禁止使用当成绝对界线。

每个词都可以添加自己的联想：填写另一个已有词、关系类型及笔记。关系按统一词条编号双向保存，同一对词、同一类型再次保存更新原笔记；可编辑笔记或移除个人关系。个人整理与内置用法对照分别标注，存入独立 `word_associations` 表，重启和来源索引重建均保留，不改变学习卡片和 FSRS。内置关系可在 `server/association-catalog.js` 扩充。

双向练习仅在核对答案后显示折叠的“联想一下”，不提前泄露提示。浏览联想、朗读或保存笔记不增加学习次数、熟悉词数或能力成果。

## 复习短文

打开 http://127.0.0.1:3000/#reading 。入口按生成时间列出所有已保存短文，标题、正文、生成时的目标词快照、创建时间和完成次数不会被后续文章覆盖。首篇《一座城市的多重选择》（`One City, Many Choices`）将城市、环境、健康、教育、就业、科技、文化及论证表达串成一条完整叙事。生成时从数据库读取 `learned_at`，只有真正学过且正文中实际出现的词条才会保存为本篇目标；仅导入或收藏的未学词不算。

- **高亮精读**：在完整英文语境中标出已学词，可切换逐段中文译文。
- **关键词挖空**：隐藏正文中的目标词，支持逐个或全部揭晓；同一个词重复出现时会重复练习，但覆盖统计只计一个词条。
- **看中文背英文**：逐段根据中文尝试复述，再单独核对英文。
- **完成记录**：只记录短文回顾次数，不伪造单词评分，也不改变 FSRS 到期时间。

短文保存在 SQLite 的 `review_readings` 表中，每篇独立记录正文、目标词和回顾进度。当前首篇针对雅思主题精练词汇编写；在本地现有的 120 个已学主题词全部保留时，正文覆盖 120 / 120 个词条，其中 80 个单词、40 个短语。

## 听力手册

打开 http://127.0.0.1:3000/#listening 。听力手册只保留三件事：是否听过、是否有逐字稿、听力笔记。

1. **添加单集**：粘贴 YouTube 链接并读取标题；重复添加会打开已有记录。
2. **记录状态与笔记**：单集页勾选“我听过这一集”，填写一份可持续修改的听力笔记。
3. **逐字稿与重点词语**：没有文稿时可直接读取该 YouTube 视频的英文字幕轨。系统会核对视频 ID、标题与 BBC Learning English 频道，并在隔离线程中限时执行；若 YouTube 直连失败，再尝试经过严格匹配的字幕镜像。逐字稿可直接编辑，保存后原有关键词解析自动失效；点击“提取重点词语”会优先识别节目 recap 中明确讲解的词汇和表达，再补充正文中的主题词，并附已有中文释义与原句。

列表只展示全部、已听、有逐字稿和有笔记的数量。旧版的多次记录、难点片段、复盘、词句关联和已下载音频仍保存在原数据表中，但不再出现在主界面，也不会影响 FSRS 排程。旧版最近一次非空笔记会迁移为单集笔记。

## 语境拼图与能力记录

打开 `/#puzzle`，或在轻量词汇练习结束后点击“用这批词玩拼图”。每轮最多三句，只选择未归档且已学或手动标熟悉词的关联双语例句。来源练习中的拼图只选该轮实际评分过的词；没有合适材料时显示空态，不拼凑成果。例句要求目标词形明确匹配、句长 4–24 词。

每句按真实历史依次进入**词块拼句 → 首字母补词 → 独立补关键词**，每次只减少一种支持。使用参考句提示后完成会单独记录为“借助提示”，不升级；答案不同只记录已核对，不做语义判错；跳过不计成果。独立拼句和补词分别标注，不等同于自由表达能力。重复做同一句仍保留练习历史，积累总数按不同句子去重。

`/#records` 的记忆维度来自首次学习评分，听辨维度来自无字幕且自评理解大意或大部分的听力记录，均明确标注“自评”。表达维度展示拼图的具体句子、任务、辅助状态和日期；同句、同任务、同辅助状态显示最近一次。记忆按未归档卡片、听辨按篇目、表达总数按独立完成的句子去重。

拼图与成果存入 `puzzle_sessions`、`puzzle_attempts`，不会写入 FSRS。提示与作答进度保存在 SQLite，当前会话编号和未提交词块/输入保存在浏览器标签页，刷新可以继续；重复提交不推进后续题目或重复计数。无需 AI 密钥。

## 生词本怎么用

直接打开 http://127.0.0.1:3000/#notebook ，点击“添加词条”。英文和中文释义必填，其他字段可选；同一英文允许收录不同释义，相同英文和释义会提示重复。

词书预览、生词本、阅读表达、书架和翻卡后的答案显示词性，例如 `n. 名词`、`vt. 及物动词`、`adj. 形容词`。同一词可有多个词性，短语标明名词短语、动词短语等；“单词/短语”仍表示词条形式。

全部内置词条已标注词性。精选词按收录释义人工整理，扩展词从 ECDICT 保留释义的词性前缀提取并做少量明确补订，尚未全部人工审校。编辑词条时可输入缩写或中文，例如 `n. / v.` 或 `名词 / 动词`。新词留空时匹配词库中已知词性，未知词显示“词性待补充”；已有词条可主动清空。重复导入不会覆盖用户修改的词性。

SQLite v5 启动时自动给已有词条补充词性，包括归档和熟悉词。不会改动释义、编号、FSRS 模型、到期时间或练习历史；保存中的旧练习在揭晓答案时也能显示对应原词条的词性。

1. 用“管理分类”建立自己的分类，例如“工作沟通”“旅行口语”。可重命名或移除分类；移除后，词条移入“未分类”。
2. 点击星标标记重点，或使用“遮住释义”逐条回想。暂时不学的词条可以归档，恢复后保留原复习记录。
3. 在“双向练习”点击 **一键开练**，默认中译英、翻卡自测，每轮最多 10 个、新词最多 3 个，到期词不足时不增加新词补满。方向、方式、词书偏好保存在当前浏览器。“自定义练习”保留完整筛选、5–100 个数量、纯 **到期复习**、纯 **学新词** 和 **自由练习**；其中普通智能混合仍按约 7:3 并在不足时补足。
4. 尚未学习的新词优先安排用户主动记录或从内容中收藏的单词与短语，再安排纯词书导入项；同一优先级内按加入顺序学习。已学词仍严格按 FSRS 到期状态与紧迫程度排序，不因来源改变复习顺序。
5. 输入答案后核对参考答案，也可以直接翻卡。系统比较参考写法，忽略大小写等基础差异，不进行语义判错；同义表达由自己核对，再选择“忘记了 / 想起很难 / 想起来了 / 轻松想起”。
6. 完成后查看结果，或单独重练本组薄弱项。“薄弱项”指最近一次双向练习中自评忘记或吃力的词条；练熟后会移出该筛选。

每组练习和进度保存到 SQLite。刷新页面可继续当前练习；关闭后也可在“最近的练习”中继续。会话使用开练时的词条快照，期间编辑词条不会改写当前题目；到期评分若发现卡片已被其他窗口复习、编辑或归档，就不会覆盖新的排程。

侧边栏“**双向练习**”每次主动点击会打开一键入口；旧的未完成练习可从“最近的练习”继续。刷新作答页或轻量收尾页会恢复当前进度。智能混合不会提前抽取未到期旧词。

### 轻量练习与收尾

- **动态减负**：只读取同来源、分类、类型和重点范围最近 30 分钟的双向练习评分。最近 5 次中有 2 次 `again/hard`，新词预算降为 1；最近 3 次有 2 次 `again`，或最近 5 次有 3 次 `again/hard`，预算降为 0。本轮预算只降不升，移除尚未展示的新词，不增加学习或复习记录。下一轮按近期表现重新计算；这些阈值是可调整的产品策略，不是 FSRS 参数。
- **手动减负**：“这一轮轻一点”保留当前题和已翻开的答案，移除后续新词，同范围内 30 分钟暂停新词。“继续一小轮”和重新一键开练都沿用这一选择。没有到期词且预算为 0 时进入空队列收尾，不提前重复旧词。
- **自由收尾**：完成后可继续、读熟词短文或今天结束，三者均可直接选择。8 篇原创短文约 60 词；重点词必须全部已学或已标熟悉，至少一个本轮顺利想起，并排除本轮吃力词作为重点。只保证重点词的学习依据，不保证整篇词汇均熟悉。
- **素材降级**：没有匹配短文时给出至多 2 条本轮已学词的关联双语例句；没有例句时明确提示休息。英文支持朗读和按需展开译文。阅读、朗读、完成收尾均不写单词 FSRS 或例句回忆评分；重复完成和重复续轮请求幂等。

## 熟悉词

在生词本词条旁、双向练习中、练习结果页或间隔复习页点击“标记熟悉”：

- 词条仍保留在生词本、分类和词书中，可编辑和查看；“已熟悉”筛选可集中管理，“正在学习”显示学过且未标记熟悉的词，“未学习”单独管理未开始的新词。
- 从到期队列、自由练习、词书练习、薄弱项重练和提醒中排除。
- 保存过的练习在恢复或提交答案时也会检查熟悉状态，自动跳过熟悉词，不计入作答次数，不修改复习时间。
- 点击“恢复学习”清空当前记忆模型；曾学过的词立即进入待复习，从巩固开始，未学过的词回到新词列表。累计复习次数、笔记和练习历史保留。如果词条还处于归档状态，需同时恢复归档。
- 重复导入、跨词书复用、重新收藏文章表达、编辑词条都不会自动清除熟悉状态。

“想起来了／轻松想起”仅代表这一次的表现，会继续安排复习；它们不会自动标记熟悉。仅对确定不需复习的词使用“标记熟悉”。相同英文、释义的共用卡片共享熟悉状态，一词多义的独立卡片分别管理。

## 复习提醒

在生词本里打开“提醒设置”，选择本地时间并开启每日提醒。到点且仍有待复习词条时触发；打开页面时若当天提醒时间已过，也会检查。

- 默认使用站内提示；点击“允许浏览器通知”后，由浏览器请求通知权限。
- 每个浏览器每天最多提醒一次，多页面共享去重标记。
- **页面和本地服务必须保持运行**。关闭页面、电脑休眠或浏览器暂停后台计时后，不能保证按时通知；当前没有后台推送或离线提醒。
- 所有生词本、双向练习和提醒功能均不需要 AI 密钥。

## AI 配置

```bash
cp .env.example .env
```

编辑 `.env`，填入自己的 OpenAI 兼容服务：

```dotenv
OPENAI_API_KEY=你的密钥
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4o-mini
AUTO_GENERATE=false
```

接口需支持 `POST /chat/completions` 与 `response_format: {"type":"json_object"}`。密钥只在后端使用，`.env` 已被 Git 忽略。配置后重启服务。启动进程中已有的同名环境变量优先于 `.env`；若遇到连接失败，请检查是否继承了其他项目的接口配置。

`AUTO_GENERATE=true` 且密钥已配置时，服务运行期间按保存的偏好每天生成一篇练习。按服务器本地日期判断，每分钟检查；失败后最多每小时重试。关闭服务期间不会运行，也不会补生成过去日期的内容。生成练习保存为文章，阅读时自行收藏想复习的表达。

新闻订阅只使用 RSS 标题与摘要作为参考，保留来源链接，不自动批量抓取或冒充完整原文。需要精读时，用户可在发现页为某条摘要补充全文，或使用“同步指定文章”保存标题、来源、链接与正文；正文、分析、标注和练习状态均保存在本地 SQLite 中，不依赖模型密钥。内置原创与 AI 生成内容在页面中明确标注。AI 输出通过结构校验，教学内容准确性仍需人工核对。

## 复习规则

使用 [ts-fsrs 5.4.2](https://github.com/open-spaced-repetition/ts-fsrs) 的 **FSRS-6**，根据每个词的难度、记忆稳定性、真实间隔及本次评分更新排程。目标回忆成功率设为 **90%**，这是模型目标，不是“已掌握90%”，也不保证个人实际正确率。目前采用库的默认参数，尚未用个人记录训练参数。

四档反馈描述**看答案前**的回忆，不是四档永久掌握程度：

| 评分     | 何时选择             | 仅新词首轮的短期巩固 |
| -------- | -------------------- | -------------------- |
| 忘记了   | 答错，或看答案才知道 | 1 分钟后             |
| 想起很难 | 费力，但独立答对     | 6 分钟后             |
| 想起来了 | 正常回忆并答对       | 10 分钟后            |
| 轻松想起 | 毫不费力、立即答对   | 30 分钟后            |

- 表中的分钟数只属于新词首轮学习步骤，不是四档评分的固定间隔。“想起来了”显示 10 分钟，是为了在首次接触后用一次短间隔回忆确认记忆，而不是认定用户只能记住 10 分钟。
- 学习步骤使用库的 `1m / 10m`；通过官方 `LearningSteps` 扩展点让新词首次 Easy 仍在 30 分钟后巩固。真实评分照常进入模型，不伪装成 Good。之后才进入 FSRS 计算的日级复习，所有阶段都不会自动“毕业为熟悉词”。
- 长期复习中选“忘记了”会降低稳定性、累计遗忘，并在 10 分钟后重学。表中的首次间隔不适用于所有后续阶段；页面显示当前卡片四种评分的实际预计间隔，提交时重新计算。
- 智能混合、学新词和到期复习共用排程及完整日志。智能混合中的旧词必须由 FSRS 判定到期，评分后更新模型；新词首次评分建立模型。对已学词的自由练习、提前重练薄弱项不更新模型，避免把连续看答案当成长期记忆证据。
- 复习组完成后显示本组最早下次时间，分钟级任务到点后再次进入到期队列，不在固定题数组中提前重复。保持页面打开时，间隔复习页每分钟更新队列；每日通知不是逐词闹钟。
- 到期前重复评分会被拒绝，双击同一题不会重复更新模型；旧会话、旧页面不得覆盖已经变更的排程。

SQLite v4 迁移按时间顺序回放旧 `reviews`，补充模型状态，保留原到期日期、累计次数、熟悉标记、归档、笔记和旧练习。未留下间隔复习记录的词从新词开始；此前主动“恢复学习”的词也重新巩固。自由练习记录不参与回放。升级不会突然重排所有卡片，下一次到期作答开始按新规则安排。

SQLite v6 增加 `learned_at`，通过旧复习评分和已完成的练习记录识别真正学过的词。只导入、收藏、打开练习或翻卡均不算完成学习。旧自由练习会保留“学过”的事实，但不伪造 FSRS 模型历史；没有模型的已学词在下次到期评分时初始化模型。升级保留全部原排程、词性和内容，只将未学词排除出待复习、提醒及对应计数。旧到期会话混入的新词会自动跳过，不计作学习。

SQLite v7 修复旧自由练习首次评分未纳入模型的问题：当首次真实评分来自旧自由练习，且早于所有正式复习时，补入这一条初次学习证据，再回放已有正式评分。重复自由练习不重复增加模型次数，现代版本已经同步记录的首次评分不会再计入。发现编辑、主动恢复或模型次数不一致时保留现状，不擅自撤销用户操作。只修复模型，不移动现有到期时间，不修改原始历史或累计正式复习次数。刷新练习页面后，按钮根据补全后的模型展示预计间隔；真正的新词仍使用上表中的初学步骤。

全量验证包括：整本导入 6,512 条后待复习数不增加、首次评分才开始学习、分钟级到期只出现实际学过的词、旧自由练习和旧会话迁移、全库词性零缺失。

可参考 [Anki 的 FSRS 与学习步骤说明](https://docs.ankiweb.net/deck-options.html#fsrs)。两种出题方向目前共用一个词条模型，尚未分别估计“认读”和“主动拼写”的记忆强度。

## 当前边界与后续方向

当前是本地单用户 MVP，默认仅监听 `127.0.0.1`，没有登录和多用户隔离。浏览器朗读依赖系统提供的英语语音。RSS 当前仅接入 BBC，暂不支持用户自定义源。

建议下一步根据实际学习反馈依次增加：更多英语教学来源与内容质量筛选、FSRS 个人参数训练、听力跟读、全文检索，再考虑账户同步与部署。公开部署前需要加入身份认证、用户数据隔离和模型调用额度控制。
